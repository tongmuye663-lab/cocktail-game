# バー・ミッドナイト｜カクテル作りゲーム

ブラウザで遊べるカクテル作りゲームです。ビルドもサーバーも不要で、`index.html` 1枚で動きます。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作成します（例: `cocktail-game`、Public）。
2. このフォルダの中身（`index.html` / `.nojekyll` / `README.md`）をリポジトリのルートにアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** の Source を **Deploy from a branch** にし、Branch を `main`、フォルダを `/ (root)` にして **Save** します。
5. 1〜2分ほどで `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

## 補足
- 文字は Google Fonts（Shippori Mincho / Zen Kaku Gothic New）を読み込みます。オフラインやブロック時は標準の明朝・ゴシック体で表示されます。
- 保存機能は使っていないため、ブラウザのデータは残りません。
